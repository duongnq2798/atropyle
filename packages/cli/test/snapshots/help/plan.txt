Usage: atropyle plan [options] [command]

create and check atropyle.plan.json files

Options:
  -h, --help              display help for command

Global Options:
  -V, --version           output the version number
  --chain <name>          chain, default xlayer (X Layer mainnet; env:
                          ATROPYLE_CHAIN) (choices: "xlayer", "local")
  --rpc <url>             read RPC of that chain (env: ATROPYLE_RPC)
  --deployment <file>     deployment JSON; wins over --chain (env:
                          ATROPYLE_DEPLOYMENT)
  --json                  print exactly one JSON object (schemaVersion 1)
  --no-color              print without colors
  --verbose               log every RPC request to stderr

Commands:
  init [options]          write atropyle.plan.json from flags; in a terminal
                          without --heir, ask one question at a time
  check [options] <file>  validate a plan file, check its tokens on chain and
                          show the current fee
  help [command]          display help for command
