Usage: atropyle [options] [command]

Plan, simulate, verify and prepare Atropyle inheritance vaults on X Layer. Never
reads a private key.

Options:
  -V, --version                        output the version number
  --chain <name>                       chain, default xlayer (X Layer mainnet;
                                       env: ATROPYLE_CHAIN) (choices: "xlayer",
                                       "local")
  --rpc <url>                          read RPC of that chain (env:
                                       ATROPYLE_RPC)
  --deployment <file>                  deployment JSON; wins over --chain (env:
                                       ATROPYLE_DEPLOYMENT)
  --json                               print exactly one JSON object
                                       (schemaVersion 1)
  --no-color                           print without colors
  --verbose                            log every RPC request to stderr
  -h, --help                           display help for command

Commands:
  verify [options]                     prove the policy circuit over all 2^26
                                       inputs and test step() on the processor
                                       (P9) from independent RPCs; --vault
                                       checks a vault too
  status [options] <vault>             state, deadlines, timeline, coverage and
                                       the roles of --as in a vault
  vaults <account>                     vaults where an account is owner, heir or
                                       guardian
  simulate [options] [vault] [action]  what an action would do now or later
                                       (whatIf), or the timeline of a plan file
  plan                                 create and check atropyle.plan.json files
  prepare [options] <action> <target>  prepare and simulate transactions, then
                                       hand them to your wallet; never signs
  doctor                               check Node.js, every RPC, the chain ID,
                                       latency and the deployment integrity
  mcp                                  run the Atropyle MCP server on stdio (the
                                       same server as npx -y @atropyle/mcp)
  help [command]                       display help for command
