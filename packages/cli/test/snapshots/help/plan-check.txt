Usage: atropyle plan check [options] <file>

validate a plan file, check its tokens on chain and show the current fee

Arguments:
  file                 plan file

Options:
  --as <address>       owner; defaults to "owner" in the file
  --drill              check it as a Drill
  -h, --help           display help for command

Global Options:
  -V, --version        output the version number
  --chain <name>       chain, default xlayer (env: ATROPYLE_CHAIN); xlayer works
                       after the mainnet deployment, use --deployment <file>
                       until then (choices: "xlayer", "local")
  --rpc <url>          read RPC of that chain (env: ATROPYLE_RPC)
  --deployment <file>  deployment JSON; wins over --chain (env:
                       ATROPYLE_DEPLOYMENT)
  --json               print exactly one JSON object (schemaVersion 1)
  --no-color           print without colors
  --verbose            log every RPC request to stderr
